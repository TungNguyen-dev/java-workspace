
## Khi ngôn ngữ đích là tiếng Việt

- Tên phương, vị thuốc, tên sách cổ và thuật ngữ Đông y dùng âm Hán-Việt chuẩn; tên riêng của phương giữ hậu tố Hán-Việt (thang, tán, hoàn, ẩm, đan…).
- **Không dùng từ "tễ" hay "phương tễ"**. Dịch `剂` / `方剂` thành "bài thuốc" và chỉ dùng cách gọi này, không xen kẽ cách khác; tiêu đề chương dạng "Bài thuốc thanh nhiệt", không phải "Thanh nhiệt tễ".
- Đơn vị cổ giữ dạng Hán-Việt (`tiền`, `lạng`, `cân`, `thăng`, `đấu`…).
